Essensbestellungstool, ursprünglich entwickelt für das KALA 2027 der Pfadi Unterwalden mit folgenden Features:
-

Bestellansicht für jede Gruppe:
- 
- passwortgeschützt
- Auswahl des gewünschten Tages
- Übersicht verfügbarer Produkte und Tages- und Lagerbudget
- Filter- und Durchsuchbar nach Produktname, Kategorie und Essgewohnheiten/Allergien
- Bestätigungsansicht mit PDF-Downloadmöglichkeit

Adminbereich:
-
- passwortgeschützt
- Dashboard mit Übersicht über Gruppen, Bestellungen, Produkte, etc.
- Grundeinstellungen: Namen, Bestellzeitpunkte, Budget pro Person, etc.
- Gruppenerstellung mit Eingabe Personen für Budgetberechnung
- Produkteimport aus Excel mit Vorlage
- Übersicht bestätigter Bestellungen mit Bearbeitungsmöglichkeit
- Export der Tagesbestellungen gesamt und als Kommission pro Gruppe

Auf jedem gängigen Webhost installierbar:
-

Anforderungen:
-
- Apache oder Nginx mit PHP-FPM / mod_php
- PHP >= 8.3
- MySQL >= 8.X oder Maria DB >= 10.X
- UTF-8 / utf8mb4
- PDO / PDO_MySQL
- mbstring
- openssl
- session
- json

Falls du das Tool auch für dein Lager benutzen möchtest und Unterstützung brauchst, kannst du dich gerne bei Spion melden.
